Sitio web informativo y funcional desarrollado con HTML, CSS y JavaScript para registrar estudiantes interesados en tres conferencias tecnológicas organizadas por la Facultad de Ingeniería y Arquitectura de la Universidad Americana (UAM).

## 🎓 Características
- Página de inicio con misión, visión y carrusel de imágenes.
- Detalles de tres conferencias tecnológicas.
- Formulario de registro con validaciones básicas en JavaScript.
- Diseño limpio, moderno y adaptable.

## 🛠️ Tecnologías Utilizadas
- HTML
- CSS3 (Flexbox, diseño responsive)
- JavaScript (validación de formularios)
